# school-hosting

Хостинг учебных проектов для онлайн-школы программирования. Учитель подключает сайт или Telegram-бота ученика по ссылке на репозиторий, и проект запускается без работы в консоли.

Сборку и запуск делает [Coolify](https://coolify.io), код хранится в [Forgejo](https://forgejo.org). Этот репозиторий содержит **мастер подключения**: небольшой сервис между ними.

## Что делает мастер

- Определяет тип проекта по файлам: статический сайт, сайт на Flask, FastAPI, Django или Express, бот на Python или Node.js.
- Задаёт вопросы, только если сам не может решить. Например, когда в репозитории и Python, и Node.js.
- Дописывает в репозиторий файл `school.toml` с описанием проекта, `requirements.txt` и `.python-version`, если их нет.
- Создаёт приложение в Coolify с адресом, лимитами памяти и процессора и командой запуска.
- Проверяет каждый коммит перед сборкой. Не пропускает токены в коде, файлы больше 20 МБ, майнеры, сетевые сканеры и исполняемые файлы.
- После запуска следит за проектом. Замечает, что программа падает или сайт не открывается. Останавливает проект, который 10 минут подряд упирается в лимит процессора.

## Устройство

| Путь | Что там |
|---|---|
| `master/app/analyze.py` | Определение типа проекта и команды запуска |
| `master/app/checks.py` | Проверки коммита перед сборкой |
| `master/app/pipeline.py` | Подключение проекта, обработка пуша, контроль нагрузки |
| `master/app/clients.py` | Клиенты к API Forgejo, Coolify, Telegram и Docker |
| `master/app/main.py` | Веб-интерфейс учителя и приём вебхуков |
| `master/tests/` | Тесты определения типов |
| `docs/spec.md` | Техническое задание на всю систему |
| `scripts/push-master.sh` | Выкладка мастера на тестовый сервер |

## Запуск

Мастер разворачивается в Coolify как приложение Docker Compose из папки `master`. Переменные окружения перечислены в `master/docker-compose.yml`:

- `CF_API_URL`, `CF_TOKEN`, `CF_PROJECT_UUID`, `CF_SERVER_UUID`, `CF_KEY_UUID`: доступ к Coolify и куда создавать приложения;
- `FORGEJO_URL`, `FORGEJO_TOKEN`, `FORGEJO_SSH`, `ORG`: доступ к Forgejo;
- `MASTER_URL`, `WEBHOOK_SECRET`: адрес мастера и секрет вебхуков;
- `MASTER_USER`, `MASTER_PASSWORD`: вход учителя в панель;
- `MASTER_EXTRA_USERS`: дополнительные входы в виде `логин:пароль,логин2:пароль2`;
- `APPS_DOMAIN`: домен для сайтов учеников, например `school.ru` или `1.2.3.4.sslip.io`;
- `NOTIFY_TG_TOKEN`, `NOTIFY_TG_CHAT`: необязательные уведомления в Telegram.

Тесты:

```bash
cd master && python -m pytest tests
```

## Что пока не проверено

- Django, Next.js и проекты со сборкой перед запуском.
- Бот на Node.js с настоящим токеном.
- Постоянная папка для данных проекта не подключается.
- Вебхуки, пришедшие во время перезапуска мастера, теряются.
